# Anahtar Kelime Tezaurusu (v1.0)

★ = çekirdek terim (her kaynakta mutlaka çalıştırılır). Diğerleri genişletme terimleridir: çekirdek terimlerin gürültülü ya da zayıf kaldığı kaynaklarda çalıştırılır.

## A. OCR ve imla kuralları (bütün Türkçe terimlere uygulanır)

Dönem basınında OCR Türkçe karakterleri sistematik olarak bozar. Her çekirdek terim şu varyantlarla aranır:

| Karakter | Varyantlar |
|---|---|
| ı | i, 1, l |
| ğ | g, ğ, ö (nadiren) |
| ş | s, ş, $ |
| ç | c, ç |
| ö / ü | o / u |
| â, î, û (düzeltme işareti) | a, i, u; 1940 öncesi metinlerde sık görülür (ör. "hayvanât", "ziraî", "baytarî") |
| ' (kesme / hemze) | "sun'i / suni / sunî", "mer'a / mera / merâ", "mes'ele / mesele" |

Örnek: ★sığır → `sığır`, `sigir`, `sıgır`, `siğir`, `sığir`, `slğır`. Kök aramasını destekleyen veritabanlarında joker kullanılır: `sığır*`, `sig?r*`.

Dönem imlası: 1928–1940 arasında Arapça ve Farsça kökenli terkipler yaygındır ("ıslah-ı nesil", "hayvanat-ı ehliye"). Ayrıca aynı kavram için Türkçe karşılıklar ile eski terimler bir arada kullanılır (ör. "baytar" → 1930'ların sonundan itibaren "veteriner"). Her iki biçim de aranır.
